# Module 1: The Factory Floor (Environment Setup)

## Goal: 

### Eliminate friction and establish a reproducible, containerized baseline.

## Concept:

### Introduction to the "Software Factory"—an automated pipeline that removes
### manual setup.

## Action:

### Utilize a pre-configured docker-compose.yml file to spin up identical, isolated
### development environments across all attendee machines.

## Outcome:
### A working, standardized environment achieved with a single command 
### (docker compose up -d).
